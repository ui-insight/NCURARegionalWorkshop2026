## 1. #UDM (posted November 6, 2026, topic 122133241)

**Subject:** #UDM The Unified Data Model: a shared language for research administration data

The AI4RA Unified Data Model is a draft data standard for research administration. It covers the records offices keep, such as sponsors, awards, people and budgets.

Each system names and stores these records differently, so a report often starts with reconciling them. A tool built at one university has to be rebuilt at the next. An institution using the model would map each of its systems to it once. Reports and tools built on the model could then run there.

A small team at one institution wrote this draft. We need people who do this work elsewhere to read it and tell us where it is wrong, and this community is who we most want to hear from.

Browse it here: https://ui-insight.github.io/AI4RA-UDM/

Start with the Glossary tab for plain-language definitions and the Statuses tab for how proposals and awards move through their statuses. Does a definition differ from how your office uses the term? Does your office track something that is missing, or call something by a different name?

## 2. #AILiteracy, Promptulus (posted November 6, 2026, topic 122133379)

**Subject:** #AILiteracy Promptulus: an AI literacy game from AI4RA

Promptulus is a free AI literacy game from AI4RA. Its nine coaching characters each teach one habit of working with AI, including deciding whether to use AI for a task at all, breaking a job into pieces, writing prompts, choosing what context to give a model, checking the output, and reporting that AI was used. Each character gives feedback on what you submit.

Try it here: https://ai4ra.github.io/promptulus/

It needs an API key. Attendees of the NCURA Region VI/VII workshop can use the key provided. Otherwise, the site gives instructions for getting and using a free Gemini token.

Give it a try and tell us what you think. Was it helpful? Did you learn anything new? Do you have any suggestions for improvements? Reply here, or start a new topic with #AILiteracy in the subject line.

## 4. #DataScience, Data Crawler Carl (posted November 6, 2026, topic 122134755)

**Subject:** #DataScience Data Crawler Carl: plain-English questions about a spreadsheet

Hello again!

Today I'd like to tell you about Data Crawler Carl, a free demo from AI4RA. It uses an AI model to answer plain-English questions about data by writing a database query, and it shows that query with the results. It helps illustrate how AI can work with structured data using SQL-based RAG: the model writes the query and the database does the math.

Try it here: https://ui-insight.github.io/data-crawler-carl/

You can upload your own data or use the demo data built in. Please don't upload any private or sensitive data. This is a training demo, not an enterprise tool.

Note: It needs an API key. The site gives instructions for getting and using a free Gemini token.

Give it a try and tell us what you think. What did you notice in the answers? Do you have any suggestions for improvements?

We'd also like to hear about using AI for data science more broadly. Are you using AI to work with data in your office? What questions would you want to ask of your own data? How do you check the numbers an AI gives you?

## 5. #DataScience, HERD Explorer (posted November 6, 2026, topic 122135484)

**Subject:** #DataScience HERD Explorer: national university R&D data in your browser

Hey everyone,

Today I'd like to tell you about the AI4RA HERD Explorer. It's a free, open-source site for exploring the NCSES HERD Survey. It covers university research and development spending for every reporting institution from FY 2012 to FY 2024, and it runs in your browser. It has an interactive chart builder and a comparison tool.

Try it here: https://nate-layman.github.io/herd-explorer/

Note: I built this myself. While I did my best to ensure my ETL pipelines are clean, you should always double-check the primary source (https://ncses.nsf.gov/surveys/higher-education-research-development) before you rely on tools like this for decision making.

Note: The Ask page (https://nate-layman.github.io/herd-explorer/ask.html) uses an AI model to answer plain-language questions about the data, using the same SQL-based RAG approach as our other demo, Data Crawler Carl (https://ui-insight.github.io/data-crawler-carl/). Remember, when using Ask you can look at the SQL it generated, but your best bet is always to look at the primary data if you find a surprising pattern. The Ask page is the only page that needs an API key. If you don't have one, there are instructions on how to request a free token from Google Gemini.

Give it a try and tell us what you think! Did you find anything interesting, or anything that looks wrong? Do you have any suggestions for improvements?
